دیپلوی خودکار پنل HEX

با یک توکن API، پنل را روی Cloudflare Workers بساز — بدون Wrangler، بدون ترمینال

⚠ نسخهٔ استاتیک: وقتی این صفحه روی یک هاست استاتیک (مانند GitHub Pages) باز شود، مرورگر به‌دلیل محدودیت CORS اجازهٔ تماس مستقیم با api.cloudflare.com را ندارد و هر توکنی خطای Failed to fetch می‌دهد. برای کارکردِ واقعی، از نسخهٔ Worker استفاده کنید: فایل hex-deployer.worker.js را به‌صورت یک Worker روی کلودفلر دیپلوی کنید.
